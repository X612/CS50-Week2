# CS50 Week 2

This repository contains my solutions for **Week 2** of Harvard's CS50x: Introduction to Computer Science.

## 📚 Overview

In Week 2, I strengthened my understanding of programming in C by working with arrays, strings, and character manipulation. I also learned how to validate user input and encrypt text using substitution ciphers.

Topics covered:

- Arrays
- Strings
- Character manipulation
- ASCII
- `ctype.h`
- Command-line arguments (`argc`, `argv`)
- Input validation

## 📂 Completed Problems

### 🎮 Scrabble
Calculates and compares the Scrabble scores of two words based on letter values.

### 📖 Readability
Determines the readability grade level of a text using the Coleman-Liau index.

### 🔐 Substitution
Encrypts plaintext using a substitution cipher with a user-provided key after validating the key.
